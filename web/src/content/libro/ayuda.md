## Preguntas frecuentes

**¿Por dónde empiezo?** Por el primer capítulo (Linux) y seguí en orden. Y probá el
**Playground** cuando quieras experimentar.

**El código del libro no me corre.** La primera ejecución descarga Python en el
navegador y tarda ~15s. Si tu código usa `input()`, aparece una ventanita para responder.

**¿Y los ejercicios?** El curso (en GitHub) tiene ejercicios, tests y una **Liga Pokémon**
con EXP y medallas. Pronto vas a poder resolverlos también acá, en el navegador.

> 💡 Cuando algo no funcione, leé el mensaje de error con calma: casi siempre dice qué
> pasó. Y si no lo entendés, copiá el error y buscalo: el 99% de las veces ya está resuelto.

## Glosario

| Palabra | Qué significa |
|---------|---------------|
| Terminal / consola | La ventana donde escribís comandos de texto. |
| Variable | Una "caja con nombre" donde guardás un dato. |
| Tipo | La clase de dato: int, float, str, bool... |
| Función | Un bloque de código con nombre que podés reusar. |
| Bucle | Una estructura que repite código (while, for). |
| Lista / diccionario | Colecciones que guardan muchos datos. |
| Clase / objeto | El molde / un individuo hecho con ese molde (POO). |
| Test | Un programa que revisa si tu código funciona bien. |
| EXP | Puntos de experiencia que ganás en la Liga al pasar tests. |
| Commit | Un punto de guardado de tu código en Git. |
| venv | Entorno virtual: cajita aislada con las librerías del curso. |
