# 📚 Recursos útiles para tu viaje

Una colección de links comentados para cuando quieras profundizar, te trabes, o tengas curiosidad. Todo gratis. 🆓

---

## 🐍 Python — Documentación y aprendizaje

- **[Documentación oficial de Python (en español)](https://docs.python.org/es/3/)**
  La biblia de Python. Al principio asusta, pero el [Tutorial](https://docs.python.org/es/3/tutorial/index.html) es buenísimo para principiantes.

- **[Python para principiantes (python.org)](https://www.python.org/about/gettingstarted/)**
  Punto de partida oficial.

- **[Real Python](https://realpython.com/)** *(en inglés)*
  Tutoriales muy bien explicados. Algunos son pagos, muchos gratis.

- **[W3Schools Python](https://www.w3schools.com/python/)** *(en inglés)*
  Referencia rápida con ejemplos para copiar y probar.

- **[PEP 8 — Guía de estilo (en español)](https://recursospython.com/pep8es.pdf)**
  Cómo escribir código Python prolijo. Lo vas a agradecer.

## 🐧 Linux — Documentación y práctica

- **[The Linux Command Line (libro gratis, en inglés)](https://linuxcommand.org/tlcl.php)**
  El mejor libro para aprender la terminal. PDF gratuito.

- **[Ubuntu — Tutoriales oficiales](https://ubuntu.com/tutorials)**
  Si usás Ubuntu (recomendado para empezar).

- **[explainshell.com](https://explainshell.com/)**
  Pegás un comando y te explica qué hace cada parte. **Magia pura.**

- **[WSL — Instalación en Windows (Microsoft)](https://learn.microsoft.com/es-es/windows/wsl/install)**
  Si estás en Windows, esto te instala Linux adentro.

- **[ShellCheck](https://www.shellcheck.net/)**
  Revisa tus scripts bash y te dice qué está mal.

## 🛠️ Herramientas que te van a servir

- **[Visual Studio Code](https://code.visualstudio.com/)**
  El editor de código más usado. Gratis. Instalá la extensión de Python.

- **[Thonny](https://thonny.org/)**
  Editor súper simple, ideal para principiantes absolutos.

- **[Git — Control de versiones](https://git-scm.com/book/es/v2)**
  Para guardar el historial de tu código. El libro "Pro Git" está en español y es gratis.

- **[Replit](https://replit.com/)**
  Programá Python en el navegador, sin instalar nada. Útil para probar rápido.

## 🆘 Cuando te trabes (te va a pasar, a todos nos pasa)

- **[Stack Overflow en español](https://es.stackoverflow.com/)**
  Buscá tu error acá. Seguro alguien ya lo tuvo.

- **Buscá el error en Google.** Copiá el mensaje de error exacto y pegalo. En serio, esto es el 50% de programar.

- **[ChatGPT](https://chat.openai.com/) / asistentes de IA**
  Útiles para que te expliquen un concepto de otra forma. Pero **escribí tu propio código**, no copies sin entender.
