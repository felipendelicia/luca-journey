🏟️ Líder Clay: Predecir números

Clay, el minero de Driftveil, predice dónde están los minerales a partir de los datos de excavación. En ML, la regresión predice un NÚMERO (no una categoría). Predecí el CP de un Pokémon a partir de su nivel. ¡Derrotá a Clay!

📦 Código base — ya está disponible, no lo escribís (lo podés usar en tus funciones) 
import numpy as np
# Relación: CP ≈ nivel * 3.5 + 10 (con algo de ruido)

                    [8], [12], [18], [22], [28], [32], [38], [42], [48]])
