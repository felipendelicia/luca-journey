🏟️ Líder Lt. Surge: Calculadora de combate

El Teniente Surge es fanático de los Pokémon eléctricos y de la potencia pura. Construí una calculadora de combate con funciones puras que calculen daño, efectividad y resultado final. ¡Derrotá a Lt. Surge!

📦 Código base — ya está disponible, no lo escribís (lo podés usar en tus funciones) 
TABLA_EFECTIVIDAD = {
    ("agua",     "fuego"):    2.0,
    ("fuego",    "planta"):   2.0,
    ("planta",   "agua"):     2.0,
    ("electrico","agua"):    2.0,
    ("fuego",    "agua"):     0.5,
    ("agua",     "planta"):   0.5,
    ("planta",   "fuego"):    0.5,
    ("agua",     "electrico"): 0.5,
}
