🏟️ Líder Grant: Validador de entradas

Grant es paleontólogo y líder del gimnasio de Cyllage. Sus Pokémon roca son duros como las reglas: si una entrada no cumple las condiciones, el programa debe avisarlo con un error claro. Aprendé a usar raise ValueError para validar datos. ¡Derrotá a Grant!
