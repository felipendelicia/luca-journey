🏟️ Líder Blaine: Pokémon evolucionados

Blaine conoce los secretos de la evolución Pokémon. En este proyecto vas a usar herencia para modelar Pokémon que evolucionan: subclases, métodos especiales y todo el poder de la POO. ¡Derrotá a Blaine!

📦 Código base — ya está disponible, no lo escribís (lo podés usar en tus funciones) 
# Clase base ya definida (la usarán las subclases)
class Pokemon:
    def __init__(self, nombre, tipo, nivel):
        self.nombre = nombre
        self.tipo = tipo
        self.nivel = nivel

    def __str__(self):
        return "%s (Nv.%d)" % (self.nombre, self.nivel)
