📚 Recursos útiles para tu viaje

Una colección de links comentados para cuando quieras profundizar, te trabes, o tengas curiosidad. Todo gratis. 🆓

🐍 Python — Documentación y aprendizaje

  • El Libro de Python (en español) ⭐ Un libro online buenísimo y gratis, en español. Explica todo Python desde cero con ejemplos. Ideal como complemento de este curso (¡el diseño de nuestro propio libro está inspirado en él!).

  • Documentación oficial de Python (en español) La biblia de Python. Al principio asusta, pero el Tutorial es buenísimo para principiantes.

  • Python para principiantes (python.org) Punto de partida oficial.

  • Real Python (en inglés) Tutoriales muy bien explicados. Algunos son pagos, muchos gratis.

  • W3Schools Python (en inglés) Referencia rápida con ejemplos para copiar y probar.

  • PEP 8 — Guía de estilo (en español) Cómo escribir código Python prolijo. Lo vas a agradecer.

🎓 Cursos online gratuitos (Harvard y más)

  • CS50P — Introduction to Programming with Python (Harvard) ⭐ (en inglés, con subtítulos) El curso de Python de Harvard, gratis. Pensado para principiantes, con videos, ejercicios y certificado opcional. Ideal para hacer en paralelo con este curso.

  • CS50x — Introduction to Computer Science (Harvard) (en inglés) El curso de introducción a la programación más famoso del mundo, también gratis. Más amplio (C, Python, web, bases de datos). Un golazo si querés ir más a fondo.

  • CS50 en español (freeCodeCamp) (YouTube) Hay versiones y resúmenes de CS50 con explicaciones en español en YouTube.

  • freeCodeCamp (en español) Cursos completos y gratuitos de programación, con certificados.

🐧 Linux — Documentación y práctica

  • The Linux Command Line (libro gratis, en inglés) El mejor libro para aprender la terminal. PDF gratuito.

  • Ubuntu — Tutoriales oficiales Si usás Ubuntu (recomendado para empezar).

  • explainshell.com Pegás un comando y te explica qué hace cada parte. Magia pura.

  • WSL — Instalación en Windows (Microsoft) Si estás en Windows, esto te instala Linux adentro.

  • ShellCheck Revisa tus scripts bash y te dice qué está mal.

🎮 PokéAPI — La API que usamos en el curso

  • PokéAPI — Sitio oficial API gratuita con datos de TODOS los Pokémon. La usamos desde la semana 10.

  • PokéAPI — Documentación Acá ves qué datos podés pedir y cómo.

  • Ejemplo rápido: pegá esto en tu navegador → https://pokeapi.co/api/v2/pokemon/pikachu Vas a ver el JSON con todos los datos de Pikachu.

🌐 Flask — Para el proyecto web final

  • Flask — Documentación oficial (en inglés) La referencia. El Quickstart es ideal.

  • Flask Mega-Tutorial (Miguel Grinberg, en inglés) El tutorial de Flask más famoso del mundo. Largo pero excelente.

🧪 pytest — Para los tests

  • pytest — Documentación oficial (en inglés) Todo sobre la herramienta de testing que usamos.

  • Getting Started con pytest Cómo escribir tu primer test.

📺 Canales de YouTube recomendados

En español

  • Píldoras Informáticas — Cursos de Python y Linux muy claros.
  • MoureDev by Brais Moure — Programación desde cero, comunidad enorme.
  • Fazt — Python, web y mucho más, práctico.
  • HolaMundo — Conceptos explicados simple.

En inglés (cuando ya te animes)

  • Corey Schafer — Los mejores tutoriales de Python que existen.
  • freeCodeCamp — Cursos completos de horas, gratis.

🛠️ Herramientas que te van a servir

  • Visual Studio Code El editor de código más usado. Gratis. Instalá la extensión de Python.

  • Thonny Editor súper simple, ideal para principiantes absolutos.

  • Git — Control de versiones Para guardar el historial de tu código. El libro “Pro Git” está en español y es gratis.

  • Replit Programá Python en el navegador, sin instalar nada. Útil para probar rápido.

🆘 Cuando te trabes (te va a pasar, a todos nos pasa)

  • Stack Overflow en español Buscá tu error acá. Seguro alguien ya lo tuvo.

  • Buscá el error en Google. Copiá el mensaje de error exacto y pegalo. En serio, esto es el 50% de programar.

  • ChatGPT / asistentes de IA Útiles para que te expliquen un concepto de otra forma. Pero escribí tu propio código, no copies sin entender.

TIP

💡 Consejo final: no intentes leer todo esto de una. Guardalo. Volvé cuando lo necesites. Los recursos son como las pociones: las usás cuando hacen falta, no todas juntas. ⚡
