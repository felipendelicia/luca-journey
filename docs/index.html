Capítulo1Linux: la terminal

Esta parte cubre Linux, que en el curso ves en las semanas 1 y 2 (antes de Python). La terminal es una ventana donde escribís comandos de texto y la computadora te responde. Al principio asusta, pero es la herramienta más poderosa que vas a tener.

ANALOGÍA POKÉMONPensá en la terminal como la Pokédex de tu sistema: una herramienta de texto donde cada comando es un "ataque". Aprender los comandos es como aprender los movimientos de tu Pokémon.

Cuando abrís la terminal, ves un prompt tipo felipe@maquina:~$. El ~ significa "tu carpeta personal" (tu home) y el $ dice "estoy listo, escribí tu comando".

1.1. Moverte por las carpetas

Todo en Linux está organizado en carpetas (directorios), una dentro de otra, formando un árbol. Estos tres comandos te dejan ubicarte y viajar:

Las opciones como -l o -a se llaman flags: modifican lo que hace el comando. Es como un objeto que potencia el ataque.

1.2. Crear, copiar y borrar

CUIDADOEn Linux no hay papelera de reciclaje: lo que borrás con rm, se va para siempre. Revisá siempre antes de borrar. Y nunca, jamás corras rm -rf /: intenta borrar todo el sistema.

1.3. Rutas absolutas y relativas

Una ruta es la dirección de un archivo o carpeta. Una ruta absoluta empieza en la raíz / y vale desde cualquier lado (como una dirección completa). Una relativa parte de donde estás parado:

  • . → la carpeta actual (acá mismo)
  • .. → la carpeta de arriba
  • ~ → tu home
  • / → la raíz de todo

1.4. Permisos básicos

Cada archivo tiene permisos que dicen quién puede leerlo, escribirlo o ejecutarlo. Al correr ls -l ves algo como -rwxr-xr--. Esa columna se lee así:

  • r = leer, w = escribir, x = ejecutar.
  • Se agrupan de a 3, para tres grupos: el dueño, el grupo y los otros.

En la próxima parte vas a aprender a cambiar estos permisos con chmod.

Python es famoso porque se lee casi como inglés y es ideal para aprender. Lo usan para webs, videojuegos, inteligencia artificial, análisis de datos y mucho más.

Capítulo4Variables y tipos de datos

4.1. Variables

Una variable guarda un dato con un nombre, para poder usarlo después. Es como una Pokéball: adentro guardás algo y le ponés una etiqueta con un nombre. El símbolo = se llama asignación: "guardá lo de la derecha en el nombre de la izquierda".

Las variables se pueden cambiar

Podés cambiar el valor de una variable cuando quieras: el nuevo valor reemplaza al viejo. Por eso se llaman "variables" (varían):

Reglas para los nombres

Los nombres de variables tienen algunas reglas y costumbres:

  • Solo letras, números y guión bajo _. No pueden empezar con número.
  • No llevan espacios: usá guión bajo para separar palabras (pokemon_inicial).
  • Distinguen mayúsculas: nivel y Nivel son variables distintas.
  • Elegí nombres que se entiendan: nivel es mejor que n.

4.2. Los cuatro tipos básicos

Cada dato en Python tiene un tipo. El tipo define qué se puede hacer con ese dato. Los cuatro tipos que más vas a usar al empezar son:

TipoQué esEjemplos
intNúmero entero (sin decimales)25, 0, -7
floatNúmero con decimales6.0, 3.14, -0.5
strTexto, siempre entre comillas"Pikachu", "a", ""
boolVerdadero o falsoTrue, False

Para ver el tipo de cualquier valor, usás la función type():

CUIDADOCuidado con un error común: "25" (con comillas) es texto, no un número. 25 + 5 da 30, pero "25" + "5" da "255" (pega los textos). El capítulo de input explica cómo convertir entre tipos.

13.3. try / except: manejar errores

Algunas cosas pueden fallar: abrir un archivo que no existe, convertir "abc" a número, dividir por cero. Sin protección, el programa se cae. Con try/except atrapás el error y seguís:

Atrapar errores al abrir archivos

Error comúnCuándo pasa

FileNotFoundErrorAbrir un archivo que no existe

Capítulo14Programación orientada a objetos (POO)

15.2. Polimorfismo

Polimorfismo ("muchas formas") significa que el mismo método se comporta distinto según la clase. Todos los Pokémon tienen atacar(), pero cada tipo lo sobrescribe a su manera:

CONCEPTO CLAVEEl poder del polimorfismo: tratás a todos como "Pokémon" y cada uno hace lo suyo, sin tener que escribir if tipo == "fuego" ... elif tipo == "agua" ... por todos lados. El código queda mucho más limpio.

Hay más herramientas avanzadas que vas a ver en la semana 9 del curso:
