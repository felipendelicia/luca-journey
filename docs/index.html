Capítulo0Cómo usar este libro y el curso

¡Bienvenido! Este libro tiene dos caras. Por un lado es el manual del proyecto: te explica cómo instalarlo y cómo avanzar. Por otro lado es un libro de Python: a partir del capítulo 1 podés aprender el lenguaje desde cero, con ejemplos y ejercicios.

Todo está pensado para alguien que nunca programó. No hace falta saber nada de antes. Vamos con calma y con temática Pokémon. 🐍

0.1. ¿Qué es este proyecto?

Es un curso completo de Linux y Python, dividido en 12 semanas (más una semana de descanso de Git) y 4 proyectos finales. Cada concepto se explica con una analogía Pokémon, cada ejercicio usa Pokémon, y cada proyecto es algo que un Entrenador usaría de verdad.

Capítulo6Condicionales: if / elif / else

if ejecuta un bloque solo si una condición es verdadera. elif agrega más condiciones, y else es el "si no".

CONCEPTO CLAVELa indentación importa. El código "adentro" del if va con 4 espacios de sangría. Python usa esa sangría para saber qué está adentro y qué afuera. No es decorativo: es obligatorio.

Python revisa las condiciones de arriba hacia abajo y entra en la primera verdadera; las demás las ignora.

Capítulo12Programación orientada a objetos (POO)

La POO te deja crear tus propios "moldes". Una clase es el molde (la especie Pikachu); un objeto es un individuo hecho con ese molde (tu Pikachu concreto).

CONCEPTO CLAVE__init__ es el constructor: se ejecuta automáticamente al crear el objeto. self es el propio objeto y va como primer parámetro de los métodos (pero no lo pasás al llamarlos).

Capítulo13POO avanzado: herencia y polimorfismo

CONCEPTO CLAVEPolimorfismo = "muchas formas": el mismo método (atacar) se comporta distinto según la clase. Así evitás llenar el código de if tipo == ....

15.3. Rutas absolutas y relativas

Una ruta absoluta empieza en la raíz / y vale desde cualquier lado. Una ruta relativa parte de donde estás parado.

  • . → la carpeta actual
  • .. → la carpeta de arriba
  • ~ → tu home
  • / → la raíz de todo

15.4. Permisos básicos

Cada archivo tiene permisos. Al correr ls -l ves algo como -rwxr-xr--:

  • r = leer, w = escribir, x = ejecutar.
  • Se agrupan de a 3: dueño, grupo y otros.

En la próxima parte vas a aprender a cambiarlos con chmod.
