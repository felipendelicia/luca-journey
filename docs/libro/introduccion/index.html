Cómo usar este libro

¡Bienvenido! Este libro te enseña Linux y Python desde cero, con explicaciones paso a paso, analogías Pokémon y muchos ejemplos. Está pensado para alguien que nunca programó: no hace falta saber nada de antes. 🐍

META

🎯 Meta: que termines programando de verdad. Cada capítulo suma una pieza nueva.

¿Qué es este proyecto?

Un curso completo de Linux y Python, con temática Pokémon. Cada concepto se explica con una analogía, cada ejercicio usa Pokémon, y cada proyecto es algo que un Entrenador usaría de verdad. Podés leer el libro de corrido o ir tema por tema.

Probá el código mientras leés

En cada bloque de código Python vas a ver un botón ▶ ejecutar: corre de verdad en tu navegador (no se instala nada). También tenés el Playground para experimentar libre.

TIP

💡 La primera vez que ejecutás algo, se descarga Python en el navegador (~15s). Después es instantáneo.

El método

  1. Leé la teoría del tema.
  2. Probá los ejemplos con el botón ▶ ejecutar (o en el Playground).
  3. Practicá: resolvé los ejercicios del curso.
  4. Jugá la Liga Pokémon para ganar EXP y medallas.
