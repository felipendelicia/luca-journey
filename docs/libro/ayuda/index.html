Ayuda y glosario

Preguntas frecuentes

¿Por dónde empiezo? Por el primer capítulo (Linux) y seguí en orden. Y probá el Playground cuando quieras experimentar.

El código del libro no me corre. La primera ejecución descarga Python en el navegador y tarda ~15s. Si tu código usa input(), aparece una ventanita para responder.

¿Y los ejercicios? El curso (en GitHub) tiene ejercicios, tests y una Liga Pokémon con EXP y medallas. Pronto vas a poder resolverlos también acá, en el navegador.

TIP

💡 Cuando algo no funcione, leé el mensaje de error con calma: casi siempre dice qué pasó. Y si no lo entendés, copiá el error y buscalo: el 99% de las veces ya está resuelto.

PalabraQué significa
